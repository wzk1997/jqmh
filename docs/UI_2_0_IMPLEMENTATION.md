# WeTravel UI 2.0 改造记录

依据用户确认的“高端沉浸式文旅 + 现代极简 UI”体系，统一摄影、深绿、白色表面、系统中文字体、留白和控件。参考图用于布局与入口组织，不将庐山示例名称、天气、价格、距离、客流或商户评分当成项目数据。

## 页面范围

| 页面 | 最终表现 | 保留的数据与功能 |
| --- | --- | --- |
| 首页 | 已确认的大图、双核心卡片、特色入口、便捷服务、精选内容 | home/list，景点、攻略、资讯与服务跳转 |
| 景区导览 | 摄影页头、搜索分类、景点目录、公交/停车/厕所快捷入口 | 原 product/list、product/view、分类与排序 |
| 园区攻略 | 摄影页头、分类胶囊、旅行内容卡片 | 原 album/list、album/view、分类与搜索 |
| 活动资讯、美食、特产 | 共用资讯杂志列表，切换真实分类 | 原 news/list、news/view；按原 cateId 筛选 |
| 景区简介与公共服务内容 | 沉浸式图文阅读，统一标题、段落与图片 | 原 home/setup_get、内容键、文本/图片与图片预览 |
| 景点、攻略、资讯详情 | 摄影封面与杂志排版，浮动首页、底部收藏分享 | 原 id、正文、交通、相册、收藏、浏览记录、分享海报 |
| 吃住行与服务 | 美食/住宿/出行切换，生活服务和反馈入口 | 原资讯、攻略分类、公共服务内容、咨询电话 |
| 我的 | 深绿摄影背景，收藏/浏览/反馈快捷入口，简洁服务菜单 | 原个人资料、状态、设置、后台入口 |
| 资料注册与编辑 | 统一表单、标签、边距和按钮 | 原字段、双向绑定、校验与提交接口 |
| 收藏与浏览记录 | 简洁记录卡片、统一空状态 | 原 fav/my_list、fav/del、保存路径、本地浏览记录 |
| 搜索 | 大标题、搜索栏、历史标签和明确搜索按钮 | 原搜索回传与历史操作 |
| 客户反馈 | 沿用已完成的现代反馈页面，纳入统一视觉 | 上一轮新增的反馈提交、个人记录、管理员回复 |
| 后台管理 | 白色导航、深绿主色、统一表单、列表、管理菜单与登录页 | 原管理员权限及管理接口；前端不显示预约统计 |

底部导航为：首页 / 景区导览 / 园区攻略 / 我的。使用原页面路径，不变更业务路由。原服务页仍注册，入口保留在首页与个人中心。分包菜单模板同步为相同四栏；修复原首页选中标识不一致。

## 明确的边界

景区免费开放。用户侧不展示景点预约、停车预约、订单、支付或理赔。旧预约代码留在仓库中，主入口不连接它；仍继承统一色彩和公共样式，以便回滚或复用。本轮不删除已有后端接口或数据库内容。

项目未发现地图坐标、第三方 AR 或全景播放器，因此未新增虚构的定位、地图、实景导航或全景按钮。“景区导览”当前是景点和交通信息目录。地图、AR、全景接入需另行提供真实资源与服务配置。

景点详情原门票攻略块不再展示；景点明确标注免费开放。不虚构营业时间、评分、价格或距离。数据中旧 `/images/cover.gif` 占位图在前端替换成浅绿图标占位，不换成其他景点照片。

## 共享视觉资源

- `style/ui_tokens.wxss`：色彩、字体、间距和圆角。
- `style/ui_common.wxss`：表面、菜单、表单、控件与状态。
- `style/editorial.wxss`：图文详情。
- `style/saved.wxss`：收藏与浏览记录。
- `style/admin_ui.wxss`：管理端视觉层。
- `images/ui/`：四栏线性图标；透明 PNG 用于微信原生导航，SVG 作为可编辑源文件。

列表沿用原 `cmpt-comm-list`，仅添加可选摄影标题、展示区域尺寸与分类事件。原 route、params、search、排序、分页、刷新与 list 事件继续使用。修复空列表触底时访问未加载分页信息的错误。

## 验证与限制

- 全部 WXML/WXS、WXSS 使用本机微信开发者工具编译器通过。
- 全部前端 JS 语法检查通过；原页面云调用路由名称与迁移前快照一致。
- `node --test tests/feedback.test.cjs tests/ui-contracts.test.cjs`：17项测试通过。
- UI 回归覆盖列表的接口/参数、资讯分类切换、公共内容页刷新保留 key、四栏路由/图标、普通服务页跳转、详情缺失数据的分享兼容、海报空封面/二维码兼容。
- 微信模拟器已验证导览与攻略真实内容加载、攻略详情、四栏导航、个人中心、吃住行服务和美食资讯页；资讯分类切换仍加载原数据。
- 模拟器现有演示数据包括“标题1”等内容，没有修改云端数据以配合设计。
- 未提交反馈、个人资料或后台写入；未进行真实拨号、分享发送或发布。反馈云函数仍需部署后进行云端联调，见 `docs/FEEDBACK.md`。
- 未宣称全部设备和每个管理页面均完成实机验收。模拟器仍有原项目与组件的警告，不等同于全项目无警告。
