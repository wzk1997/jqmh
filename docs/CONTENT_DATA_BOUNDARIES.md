# 攻略与资讯的数据边界

攻略与资讯使用独立模型和集合，通用 CMS 只复用管理代码，不合并业务记录。

| 内容 | 集合（默认 bx_ 前缀） | 游客接口 | 分类与详情 |
| --- | --- | --- | --- |
| 攻略、游玩贴士 | bx_album | album/list、album/view | album 分类，攻略详情页 |
| 资讯、公告、活动 | bx_news | news/list、news/view | news 分类，资讯详情页 |
| 景点 | bx_product | product/list、product/view | 独立景点详情；攻略可关联景点 |

攻略页“游玩贴士”使用 `album` 下的 `tips` 分类，后台在攻略模块维护。既有 `news` 下的 `tips` 分类仍属于资讯，两者按所属模块区分，不互相读取、覆盖或自动迁移。

攻略范围搜索只查询攻略和景点；全站综合搜索可聚合多个模块，但结果保留各自类型和详情路径。共享列表、样式、媒体展示工具不改变上述存储边界。

本次仅修改本地代码和本地 UI 示例，没有执行线上迁移、删除记录或部署云函数。部署后如需展示正式攻略贴士，应在后台攻略模块独立维护并发布，不会自动把旧资讯复制成攻略。

验证：149 项本地测试通过，包括攻略贴士接口、详情归属、搜索请求范围及同名内容保存、删除的跨模块隔离。

## 初始化与分类维护

自动初始化不再插入示例资讯、攻略、景点或预约，也不提供任何默认分类。分类接口只返回数据库中手动维护且已发布的分类；空分类表返回空列表，分类管理不再临时拼接“系统分类”。初始化仅保留必要集合和管理员。

分类列表提供删除操作，按所属模块检查当前内容与未发布草稿的分类引用；有引用时须先调整内容分类。删除采用现有软删除机制，不会因刷新、重启或默认配置而恢复。

“游玩贴士”如需正式使用，应在攻略分类管理里手动建立并发布编号为 `tips` 的分类。开发者工具专用 UI 预览仍是独立的内存示例，不属于数据库初始化。

153 项本地测试通过，包括空分类不补数据、初始化不插入业务记录、删除权限/确认及分类引用保护。没有执行线上清理或部署。
