# 首页配置精简

首页配置仅管理品牌名称与顶部轮播（最多 8 张）。已移除“关联园区”和“精选推荐”的表单、数据字段、校验和读取解析，前台也不再渲染相关区域或以推荐内容补充资讯。首页资讯独立读取 `news/list`。

轮播上传、保存和发布不需要园区记录。新图片经格式、大小和内容校验后保存到 `TRIP1/home_portal/SETUP_HOME_PORTAL/`，媒体展示仅为配置中的图片签发链接。已保存的旧轮播图片保持兼容。旧配置中的园区关联和精选字段在响应和后续保存中移除，不删除原内容记录。

保留 `home/portal` 和 `admin/portal_get`、`admin/portal_save`、`admin/portal_publish`、`admin/portal_upload`。轮播仍支持内容跳转，因此 `admin/portal_choices` 继续服务轮播目标选择，并检查目标模块权限。首页配置仍使用原园区管理权限，避免改变现有管理员授权。

删除旧的 `home/list`、`admin/clear_vouch` 路由与对应控制器实现。未执行旧推荐数据清理或任何线上删除操作。

157 项本地测试通过，覆盖轮播独立发布、草稿隔离、旧图兼容、上传目录和媒体签发。修改尚未提交上传或部署。
