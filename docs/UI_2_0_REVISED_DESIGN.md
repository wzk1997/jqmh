## NewsWaterfall 复用调整

首页和活动资讯页统一使用 `/cmpts/biz/news_waterfall/news_waterfall`（NewsWaterfall），统一卡片、图片比例、占位、标题和元信息样式。组件仅负责展示，不请求接口。首页由页面控制首批请求与去重后最多 6 条展示，刷新时替换；活动资讯页由原 cmpt-comm-list 控制每页 20 条、滚动追加及下拉刷新，搜索与分类接口保留。`layout=waterfall` 现在仅用于区分摄影页头，不再决定使用哪种卡片。

## 自定义底部 Tab

按最新底部 Tab 设计启用 `miniprogram/custom-tab-bar`：四个原有 tab 路由保持注册，点击仍使用 wx.switchTab；组件在挂载与页面显示时按照实际路由同步选中状态，失败时不切换选中项。浅色山峦背景、山水小屋／方向路标／折叠地图／人像使用本地 SVG 源与 PNG 展示资源，选中为绿色填充，未选中为灰紫线条。底部适配安全区域，并为四个 tab 页预留空间。参考微信[自定义 tabBar 文档](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/custom-tabbar.html)。
